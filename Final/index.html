Project Gaia: Smart Enclosure Management System

Project Description

Project Gaia will be a browser-based application for managing multiple reptile, amphibian, and bioactive enclosures from one dashboard. Users will be able to create enclosure profiles, record animal and habitat information, enter current temperature and humidity readings, track feeding and water availability, view enclosure health scores, receive care recommendations, and review saved session history.

The application will represent the first software version of a larger enclosure automation system. Future versions may connect to ESP32 sensor nodes, misting systems, lighting, heating equipment, and other physical enclosure controls.

Target Audience

The target audience is reptile and amphibian owners who manage one or more enclosures and need a central place to organize habitat information. It is especially intended for hobbyists who want better monitoring and organization without purchasing an expensive commercial enclosure-control system.

Project Innovation

Project Gaia is innovative because JavaScript will do more than display enclosure information. It will compare current readings to the preferred conditions stored for each animal, calculate an enclosure health score, identify possible problems, and generate recommendations for the user.

JavaScript objects will represent animals and enclosures, while reusable functions will handle calculations, validation, recommendations, history, and dynamic webpage updates. Asynchronous JavaScript will be used to load animal care profiles or sample enclosure data from a separate JSON file.

Platforms

Project Gaia will run as a standalone application in modern desktop and mobile web browsers. The class version will use HTML, CSS, JavaScript, and JSON without requiring physical sensors or special hardware. The application will be designed so that sensor and automation features can be added later without rebuilding the entire website.
